# Captures d’écran

Ajouter ici les captures non sensibles des vues suivantes avant une release publique:

- `catalog.png`: catalogue et filtres.
- `product-detail.png`: détail et actions produit.
- `cart.png`: panier avec résumé.
- `profile.png`: profil, thème et langue.

Les captures peuvent être générées depuis Web ou desktop avec Flutter DevTools. Elles ne doivent contenir aucune donnée personnelle réelle.
